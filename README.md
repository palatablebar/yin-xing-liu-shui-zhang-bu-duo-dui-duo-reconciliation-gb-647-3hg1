# ledgerbank 银行流水与账簿多对多对账

连锁零售财务共享组每月核对 12 个银行账户与账簿凭证。海外门店用美元和港币结算，
银行流水与业务凭证各记原币，关账却只认人民币。一笔付款可能拆成多张凭证，
多笔流水也可能合并支付一张发票；会计原先逐条手工比对，手续费与尾差经常对不上。

## 核心规则

- 候选：方向相同、**同一币种**、原币金额差 ≤ 0.02、本地日期差 ≤ 3 天。
  人民币金额刚好相等但币种不同的两组不会配对。
- 一对一、一对多、多对一都参与求解；多对一用受限子集和，最多 4 条，按金额降序枚举。
- 择一：层级优先（一对一 → 一对多 → 多对一），再按币种、金额差、日期差、业务号升序，取不重叠的组合。
- 手续费只计银行侧，不进入匹配金额；匹配组按银行人民币签向金额比例分摊手续费，尾差用最大余额法分到分。
- **原币核对**：每个币种各自平衡——银行合计 = 匹配 + 未匹配 − 手续费；账簿合计 = 匹配 + 未匹配。
- **人民币关账**：按结果快照汇率折算；匹配差额 = 原币差额整笔折算 + 折算尾差，两项分列。
- **结果版本化**：一次求解产出一个 result set，页面、CSV、清单只读 active 版本；
  换汇率重跑生成新版本，旧版完整保留，失败整体回滚，原币金额从不改写。

## 功能模块

| 模块 | 使用者动作 | 入口 |
|---|---|---|
| M1 流水采信 | 导入银行流水或账簿凭证，看到编码、分段与逐行诊断 | `POST /api/statements/import`、页面 `/` |
| M2 金额日期规则 | 查看列定义、借贷符号、币种、容差、日期窗口与默认汇率 | `GET /api/contract` |
| M3 质量隔离 | 按原因码看隔离行（含币种无法识别）并导出 CSV | `GET /api/quarantine`、`/api/quarantine.csv`、页面 `/quarantine` |
| M4 候选匹配 | 生成同币种的一对一、一对多、多对一候选 | `POST /api/candidates`、页面 `/candidates` |
| M5 多对多求解 | 求解不重叠匹配组，看原币、汇率、折算与手续费分摊 | `POST /api/matches`、页面 `/matches` |
| M5 汇率与版本 | 调整汇率重跑、查看结果版本、切回旧版 | `GET/POST /api/rates`、`GET /api/batches/{run_id}/results` |
| M6 差异与批次 | 看按币种的原币核对、人民币守恒、差异归因与批次 | `GET /api/differences`、`GET /api/batches`、页面 `/batches` |
| M7 报告导出 | 导出报告 CSV 与运行清单 JSON（含汇率与结果版本） | `GET /api/export/report.csv`、`/api/export/manifest.json`、页面 `/export` |

## 启动

```bash
docker compose up -d --build
```

打开 <http://127.0.0.1:18206/>，点「载入样例」即可跑完采信 → 质量 → 候选 → 匹配 → 差异 → 导出。

## 演示步骤

1. 首页点「载入样例」，页面顶部出现银行 22 笔、账簿 19 笔、匹配 11 组。
2. 打开「隔离区」，看 8 条隔离行的原因码，下载隔离 CSV。
3. 打开「候选」，核对一对一 7 条、一对多 2 条、多对一 2 条。
4. 打开「匹配」，看 11 组匹配、汇率与手续费分摊合计 22.31 元。
5. 打开「批次」，核对每个币种的原币守恒、人民币关账守恒、结果版本。
6. 打开「导出」，下载报告 CSV 与运行清单 JSON，核对同一 result_id。

多币种样例：

```bash
curl -sX POST 'http://127.0.0.1:18206/api/demo/run?bank=bank_statement_fx.csv&ledger=ledger_book_fx.csv'
```

美元与港币各按原币配对；USD 组的 0.02 原币尾差折算后为 0.15 人民币，
拆成「原币差额折算 0.14 + 折算尾差 0.01」两行。在「匹配」页把 USD 汇率改成 7.50
可生成新版本，旧版本仍可在「批次 → 结果版本」切回。


## 页面

- `/` 工作台：左右对照、固定合计条、差异行左边框，金额按原币展示并标币种。
- `/quarantine` 隔离区。
- `/candidates` 候选清单。
- `/matches` 匹配组：原币、汇率、人民币折算、折算差异、手续费，含汇率调整表单。
- `/batches` 按币种原币核对、人民币关账、结果版本历史与切回。
- `/export` 导出，标明当前生效结果与汇率。

## 已知不覆盖

- 凭证拆分到科目层的匹配不做，只按银行账户与金额对账。
- 币种登记为 CNY/USD/HKD；其他代码或未知符号进隔离区 `CURRENCY_UNKNOWN`，不会静默按人民币处理。
- 汇率按批次快照手工调整，不接外部行情源；本位币（CNY）汇率恒为 1。
- 跨年账单不分摊手续费，一次运行只对应一份月度流水。
